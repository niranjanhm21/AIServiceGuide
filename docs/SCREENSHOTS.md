# AIServiceGuide — Application Screenshots

This document contains the visual documentation checklist for AIServiceGuide.

Screenshots should be captured from the actual running Android application. Do not use mockups or edited images as proof of implemented functionality.

## 1. Welcome / Home Screen

**Suggested filename:** `home-screen.png`

Capture:
- Application home screen.
- Main navigation or welcome section.
- Overall application layout.

## 2. Chat Interface

**Suggested filename:** `chat-interface.png`

Capture:
- User entering a question.
- Conversation interface.
- AI assistant response.

## 3. Government Service Guidance

**Suggested filename:** `service-guidance.png`

Capture:
- A relevant government service query.
- Retrieved service information.
- Eligibility or service details, if implemented.

## 4. Required Documents

**Suggested filename:** `required-documents.png`

Capture:
- A service's required document list.
- Any document checklist or related guidance.

## 5. Application Procedure

**Suggested filename:** `application-procedure.png`

Capture:
- Application steps.
- Instructions for completing a government service application.

## 6. Suggested Screenshot Folder Structure

```text
docs/
└── screenshots/
    ├── home-screen.png
    ├── chat-interface.png
    ├── service-guidance.png
    ├── required-documents.png
    └── application-procedure.png
```

Only add screenshots for features that are actually implemented and working.

## 7. Screenshot Guidelines

- Capture screenshots from the real application.
- Use readable screen content.
- Avoid exposing API keys, personal information, or private data.
- Use consistent image dimensions where practical.
- Prefer PNG format.
- Do not include fabricated or misleading application screens.

## 8. README Integration

Once genuine screenshots are available, selected images can be displayed in the main README using relative Markdown paths.

Example:

```markdown
![Application Home Screen](docs/screenshots/home-screen.png)
```
